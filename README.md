# 🎬 Movie Night

**Movie Night** is a professional-grade mobile application that allows users to explore trending movies, search for their favorites, and watch official trailers. Built with a focus on high-energy aesthetics and clean architecture, it serves as a showcase of modern front-end engineering.

---

## ✨ Key Features

*   **Premium UI/UX**: Dark mode experience with glassmorphism, neon aesthetics, and smooth animated transitions.
*   **Real-time Search**: Instant movie search powered by the TMDB API.
*   **MVC Architecture**: Clean separation of concerns between Models, Views, and Controllers for scalability.
*   **Persistence**: Save your favorite movies locally using `AsyncStorage`.
*   **Media Integration**: Watch official YouTube trailers directly within the app via WebViews.
*   **Advanced Animations**: High-performance 60FPS animations using the React Native `Animated` API.

---

## 🛠️ Technical Stack

*   **Framework**: [React Native](https://reactnative.dev/) (Expo Router)
*   **Language**: [TypeScript](https://www.typescriptlang.org/)
*   **State Management**: React Context API
*   **API**: [TMDB API](https://www.themoviedb.org/documentation/api)
*   **Styling**: StyleSheet API with a Custom Theme
*   **Navigation**: Expo Router (File-based routing)

---

## 🏗️ Architecture

The project follows the **Model-View-Controller (MVC)** pattern:

*   **Models**: Defines data structures and API service logic (Axios).
*   **Views**: Reusable UI components and screen layouts with glassmorphic styling.
*   **Controllers**: Custom hooks that manage business logic and data fetching.
